# QuranSPLNGB

125 Words Of Quran Practise Website By Ziauddin.

## Features
- **Interactive Quiz**: Test your knowledge across every field (Meaning, Part of Speech, Occurrences, and Spelling).
- **Study Mode**: Includes a study mode with flashcards word data and whitelist toggles.
- **Customizable Themes & Modes**: Choose from different site themes with dark/light mode toggle to give a better user experience.
- **Whitelisted Known Words**: Filter out words you already know to focus entirely on remaining vocabulary.
