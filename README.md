# QuranSPLNGB

Interactive Qur'anic vocabulary study guide, quiz, and sight-spelling application designed to help learners master essential Qur'anic words.

## Features
- **Interactive Quizzes**: Test your knowledge across multiple fields (Meaning, Part of Speech, Occurrences, and Arabic Sight-Spelling).
- **On-Screen Arabic Keyboard**: Specialized layout optimized for mobile and desktop sight-spelling.
- **Study Mode**: Interactive flip-cards with detailed word data and whitelist toggles.
- **Customizable Themes & Modes**: Choose from Indigo, Emerald, Obsidian, Sunset, and Cyber color palettes with instant Dark/Light mode switching.
- **Whitelisted Known Words**: Filter out words you already know to focus entirely on remaining vocabulary.
